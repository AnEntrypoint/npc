# train — working notes

WebGPU trainer for NPC brains (PPO primary; neuroevolution + Hebbian plasticity secondary, plateaus at 60-75% of bots). One HTML file, no Python, no server. Contracts SPEC.md / GAMES.md / runtime/README.md; measurements AB-ARCHIVE.md + runs/NEXT-ROUNDS.md; plan runs/GAME-DESIGN.md.

## Decisions (user)
- Any game we make must train here; games are plugins (JS Env + optional WGSL port). Real-time .io-style continuous play, never turn-based; NPCs play the real game at `tickHz` and training is that same fixed-step sim run faster - no simplified NPC mechanics: the product keeps learning live, so per-NPC inference cost and online-learning stability are constraints (tiny Brain, plugin Env, WebGPU trainer, self-play league).
- MMO-scale target (Neural MMO-like): `realm`, `blob` = small test bed. Emergent cooperation/competition/survival; AI must vastly beat the scripted bots; learners compete with each other (self-play + league) more than with bots; bots stay the fixed benchmark (16 learners vs 16 bots, difficulty 100, fresh respawn) in eval worlds.
- Fixed by plan: one workgroup per world, 64 threads = 64 entities, K ticks per dispatch, islands + graveyard + select + ring migration, held-out eval worlds, CPU fallback, genome JSON export.

## Architecture
- Kernel (src/shader.js) owns brains, think/learn/structural, graveyard, rebirth, select (bitonic), reduce; the game chunk owns the world sim. Explicit 10-binding layout shared by all 7 entry points (>= 9 storage buffers/stage; device grants 16).
- Genome = 20 params + sparse edges packed `src | dst<<8`. Lamarckian. Fitness = life reward - world-mean baseline*life - penalty*ops/1000, blended 0.6 life + 0.4 parent fitness (`EVO_DEFAULTS.lifeWeight`).
- World buffer = `WORLD_HDR_WORDS` 28 header words (stats at word 8, `NSTATS` 20) + `worldWords`; `STAT.GAME0` 9 leaves 11 game slots (realm uses 10). Both shaders template `STATS_OFF`/`NSTATS`/`GAME_OFF` from core.js - never hardcode 16 or 24. WGSL stat indices come from `STAT` (`STAT_CONSTS`); league role slots are `NSTATS + 0/2`: a literal `select(18u, 16u, ...)` survived the 16->20 growth and zeroed every h2h tick instead of crashing.
- Worlds capped by buffer limits (no chunking, edge buffers dominate); `worldCapacity()` clamps. RTX 3060 laptop; headless Chrome via gm cdp (`.gm/browser-config.json` {enable_webgpu, gpu nvidia}); workgroup storage 32768 B.
- `node serve.mjs 8123`; `node build.mjs [--check]` hashes sources into `<meta name="build-hash">` (check it before trusting a page); `index.html` is a separate single-file build - keep it current.
- runtime/npc.js mirrors core.js Brain but not exactly: no `evo.plast` factor in `learn()` (core.js:301), no biasNode (core.js:213) - bit-identical replay only at plast 1 / bias 0. PPO champions have eta 0, so Hebbian plasticity is inert: live improvement is opt-in `learnMode:'ac'` (runtime/README.md). `GpuBackend.runTests` (8/8) = init == JS env, brain parity 2e-6, env lockstep, CPU-backend equivalence.
- Perf (P9): numbers in AB-ARCHIVE.md. step() = 2 submissions; auto K (target 40 ms, cap 200); odd act stride, r_f stride 33, 4-way observe with atomicMin. Only interleaved dev/perf.html min-of-N timings are valid on this shared GPU; unordered A/Bs are void.

## Learned the hard way
- Game reward design decides learnability. Test hand-wired policies in Node before blaming the trainer. Reward hygiene: a first-tier craft worth less than selling the kit (0.25 vs 0.66) is never learned; the spawn kit must not pay more than the death penalty (-1) or suicide loops pay.
- WGSL: barriers only in uniform control flow (workgroupUniformLoad on a workgroup copy); values loaded from read_write storage are non-uniform; f32 sqrt is inexact so integer sqrt needs correction loops; cross-entity effects are victim/node-centric with lowest-index ties; `active` and `target` are reserved; one buffer cannot be bound twice; storageBarrier + workgroupBarrier when lanes exchange through global memory. Constants edited by string replace can hit the wrong occurrence - only the lockstep test catches it; a field the GPU sets at init but JS sets inside `step()` diverges only at tick 0 (`env.brain`).
- Never write another lane's readable state during the DECIDE phase: no barrier exists between lanes there, while JS's decide loop is sequential (the mage blink and the melee lunge both moved out to the top of `r_move`).
- Chrome 154: `copyBufferToBuffer` inside ONE buffer invalidates the whole command buffer (snapshots lost their rollout; league tests passed vacuously) - snapshots copy through `snapshotScratch`, `iterate()` runs in an error scope. Headless Chrome via cdp also dies in long combined runs: run tests and long training separately.
- The GPU is the only WGSL compiler in the normal loop, and a validation job that loaded `src/` before an edit does NOT validate the edit (`r69t` 10:27-11:42, `realm.wgsl.js` written 11:33). "An edit lands on the NEXT job" applies to `tests=1` too.

## Reward channels contract (realm)
- `GameDef.rewardChannels = ['survival','progress','combat','cooperation']` (0..3, `REALM_INFO.CH`). JS `env.rewardCh` Int32Array(32*4) = per-tick fixed-point x1024 at `slot*4 + channel` (bots included); `env.reward[a]` = their sum (weights 1,1,1,1). Evolution and the unweighted PPO path see only the total.
- WGSL `g_reward_channel(a, c) -> i32`, valid after g_step's final phase (own-entity reads need no barrier, other entities need a workgroupBarrier). Storage = workgroup `r_rc[64]`, two channels per i32 (`lo + hi*65536`), reset every g_step; channel words at 2608.
- survival = alive, need restore, distance shaping, animal kills, death (-1024). progress = harvest xp, craft by tier (256/1024/2048), sale gold (x8, capped 40), town-approach shaping, milestones. combat = attack xp, mob kill xp + gold, PvP kill xp + bounty (256 + 96 x victim gear tier, halving per kill, floor 1/8), boss top-damage (768), damage taken (-3 fx/hp). cooperation = great-node shares (1024), boss group reward (1536), boss/party xp, first great / boss milestones; both halve per repeat. Gold only from sales and mob kills, so boss/PvP loot cannot be farmed.

## PPO trainer (src/rl.js math + genome io, src/rlshader.js WGSL, src/rlengine.js host, dev/rllong.html, tools/rlreplay.mjs)
- Defaults = feed-forward, bias-free, bit-identical to the original; opt-in `recurrent`, `bias`, `obsNorm` (implies bias), `learnLeak`, `leakTauMax`, `rewardClip`, `valueClip`, `channelCaps`, `curriculum*`; `blockGrad: 1` default. rllong URL params (`?recurrent=1&bias=1&obsNorm=1&ticks=N`). Policy math, theta/rollout layouts, options: SPEC.md. `channelCaps` clamps the PER-TICK channel value (src/rlshader.js:640, src/rlengine.js:1010): it cannot stop survival paying partway through a life and it scales the death penalty with the alive reward, so it is NOT the lever for the survivor attractor.
- Policy = the deployed Brain dynamics exactly (softsign(2x), leak, no gating, no plasticity). Export `npc-brain/3` when bias/obsNorm/recurrent are on (hidden->hidden edge src hid0+m -> dst hid0+i = wr[m][i], plus `bias`, `leak[nNodes]`, `inputNorm` folded into W1/b1 - exact unless an obs hits the +-10 clip); plain settings export `npc-brain/2`. RealtimeNpc replays identically.
- Bindings 0..8 = theta, world, rObs, rRec, lane, partials, opt, statsOut, uniforms. realm at 32 learners fits the defaults (hidden 64 / rolloutTicks 31) - raise either only in small steps - expect a job to fail fast, not degrade. LEARNERS = game.maxLearners || game.learners (realm 32), so the realm chunk must stay <= ~16.0 KB. New shader knobs must also be listed in `shaderConfig()` (src/rlengine.js:117) - it whitelists cfg keys, so one missing there disables the knob on GPU only.
- Self-play and league: theta = live + poolSize reservoir snapshots (one per snapshotEvery); a leagueFraction of training worlds runs random slot subsets against a snapshot. Eval groups: A 16 learners vs bots, B latest vs a referenceAge-old snapshot alternating, C pure 32-learner self-play.
- Curriculum (`curriculum: 1`, rule in SPEC.md): difficulty and the self-play share step on smoothed eval life and the eval/bot ratio; flips re-init the world; state is in the checkpoint; LifeUp .12 is the realm default. It costs bit-reproducibility: updates ride the wall-clock stats report (`logSeconds`), so the SAME seed re-run moves ~0.08 EVAL - judge curriculum arms on seeds, never on a bit-identity check.
- `RlBackend.runTests()` = 21 tests (realm+blob, default + recurrent/bias/obsNorm): JS finite differences incl. BPTT, determinism, forward parity (3e-6), JS-env lockstep, GAE incl. clips, gradient+Adam (4e-8), export replay, league, hidden carry, channel caps, curriculum flips, checkpoint/import + 6 population. `fit=1` = `FIT[ev,adv,sig,std,sat,dead]`; audit runs/telemetry-audit.md.
- Population (P17, `policies` K<=8, default 1; model in SPEC.md): theta = K live slices then K x poolSize snapshots; opt = K blocks of `optStride`; one uniform + bind group per policy, kernels masked on `rl_mine(b)` = LIVE && POL==policy; training reward = sum_c w_p[c]*clamp(ch_c, caps) (un-gated at K=1, so `popWeights` works without a population). eval A = K+1 sets (last = mixed team); K>1 needs >= K+1 eval A worlds; construct `this.K` BEFORE the layout or it compiles a K=1 shader. `popWeightsEnd` anneals each role's weights to a target over `lrDecayIterations`.
