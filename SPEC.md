# train — shared spec (contract between src/, runtime/, app)

Goal: a generic, GPU-accelerated (WebGPU) neuroevolution + Hebbian-plasticity trainer for NPC brains in ANY game we make. A game is a plugin; the trainer, brain, evolution, islands, archive, UI and runtime are game-agnostic. Shipped plugins: `blob` (.io-style arena, the small test bed) and `realm` (MMO-scale world).

## Source layout (ES modules; build.mjs inlines them into one index.html by stripping `import ... from` lines and the `export ` keyword, so top-level names must be unique across files)
Build order: `src/core.js`, then every `src/games/*.js` except `index.js` (wgsl files before their game), `src/games/index.js`, `src/shader.js`, `src/engine.js`, `src/rl.js`, `src/rlshader.js`, `src/rlengine.js`, `src/app.js`.
No comments in code; names carry the meaning. No test files.

## Game plugin contract (JS side; src/games/<id>.js exports a GameDef, register in src/games/index.js)
```
GameDef {
  id, name,
  dims: { nIn, nOut, nNodes }        // nNodes<=256, nNodes > nIn+nOut; nodes 0..nIn-1 inputs, nIn..nIn+nOut-1 outputs, rest hidden
  agents, learners                   // learners are agents 0..learners-1 driven by evolved brains; the rest are scripted/other
  maxAge                             // trainer kills learners after this many lifetime ticks
  inputNames[], actionNames[], statNames[<=7]
  defaultCfg(), randomCfg(rng)       // per-world config (domain randomization)
  createEnv(seed, cfg, isEval, stats) -> Env
  wgsl                               // WGSL chunk implementing the same env on the GPU (optional; without it the game trains on the CPU backend only)
}
Env {
  observe(a, out Float32Array(nIn), tick)              // learner a
  step(actions Int32Array(learners), outputs Float32Array(learners*nOut), tick)   // advance one tick; scripted agents act inside
  reward Int32Array(learners)                       // fixed point x1024 for the tick just stepped
  dead Uint8Array(learners)                         // 1 = learner died this tick
  respawn(a, tick)                                  // reset learner a
  snapshot() -> { kind:'grid', width, height, tile:Uint32Array, agents:[{x,y,face,hp,energy,gold,evo,alive}] }   // any game may add its own kind; UI draws 'grid' generically and calls game.render if provided
  stats: Int32Array(16) shared with trainer; env adds STAT.REW_BASE/TICKS_BASE (scripted baseline) and STAT.GAME0.. game counters
}
```
Stat slots (16 x i32 per world; rewards x1024): REW_EVO 0, REW_BASE 1, TICKS_EVO 2, TICKS_BASE 3, OPS_EVO 4, BIRTHS 5, DEATHS 6, LIFE_FIT 7, EDGES 8 (assigned), GAME0..GAME6 = 9..15.

## Brain / genome
20 evolved params (eta,A,B,C,D,decay,wmax,pruneT,growP,gateT,gateMax,eps,gain,baseRate,growW,leak,inScale,-,-,mutMult). Sparse recurrent graph, edges (src,dst,w) packed `src | dst<<8` (u32) + f32 weight, cap `maxEdges`. softsign(gain*sum) with leak, novelty gate, argmax action + eps exploration; ABCD Hebbian on nonzero reward; prune/grow every 32 lifetime ticks; Lamarckian inheritance (genome = brain at death).
fitness = life reward sum - penalty * ops/1000; penalty(tick) = start + (end-start)*min(1,tick/ramp).

Genome JSON: `{ "format":"npc-brain/2", "game":"realm", "dims":{nIn,nOut,nNodes}, "params":[20], "edges":[[src,dst,w],...], "meta":{"fitness":n} }` (`npc-brain/1` = legacy arena, same layout with 6-bit packing irrelevant in JSON).
`npc-brain/3` = `npc-brain/2` plus optional `"bias":[nNodes floats]` (applied to nodes >= nIn: `x = gain * (sum + bias[j])` before the softsign; entries below nIn ignored), optional `"leak":[nNodes floats]` (per-node leak replacing the global `params[15]`: `act[j] = leak[j]*act[j] + (1-leak[j])*softsign(x)`; absent = global leak, so evolution and old files are bit-identical; the evolution GPU kernels ignore it, `Brain` and `RealtimeNpc` implement it identically) and optional informational `"inputNorm":{"mean":[nIn],"std":[nIn],"folded":true}` (never applied at run time: it is folded into the first layer at export with `foldInputNorm`, so deployed genomes take RAW observations; `folded:true` lets the trainer unfold it on import). All nodes >= nIn update simultaneously from the previous tick's hidden/output activations and the current tick's inputs, so hidden->hidden edges are ordinary recurrent edges. `genomeFromJSON`, `Brain` and `RealtimeNpc` read /1, /2 and /3; `genomeToJSON` and `RealtimeNpc.toJSON` emit /3 only when a bias entry is nonzero or a leak vector exists, otherwise /2 byte-identical to before. Evolution (CPU and GPU kernels, mutation, crossover) does not know bias or leak vectors: evolved genomes are bias-free, and GpuBackend.importGenomes drops them (CpuBackend keeps them fixed).
`foldInputNorm(W1, b1, mean, std)` (core.js; W1[hidden][nIn], b1[hidden] or null) -> `{W1', b1'}` with W1'[j][i] = W1[j][i]/std[i], b1'[j] = b1[j] - sum_i W1[j][i]*mean[i]/std[i].

## PPO trainer (RlBackend, src/rl.js + src/rlshader.js + src/rlengine.js)
Features (opts, all default off = the previous feed-forward, bias-free behaviour bit for bit): `recurrent` (leaky Elman policy trained with truncated BPTT over the rollout), `bias` (b1 hidden, b2 output), `obsNorm` (running mean/std of the observations kept by the trainer and folded into layer 1 at export), `learnLeak`, `leakTauMax`, `rewardClip`, `valueClip`, `channelCaps` (per-reward-channel caps for games exposing `g_reward_channel`), `curriculum*` (automatic difficulty and self-play controller, see below), `blockGrad` (default 1: 16-sequence block gradient kernel with `rl_select` compaction; 0 selects the older tile / one-sequence kernels). Realm at 32 learners fits the defaults (hidden 96, rolloutTicks 31) but not much more with `blockGrad: 1`: hidden 128 asks for 32784 B of workgroup storage and rolloutTicks 128 for 33232 B against the 32768 B grant, so both fail pipeline creation — set `blockGrad: 0` and both compile (measured: see AGENTS.md), at ~2.6x the gradient kernel cost. `rlLayout(nIn, nOut, hidden, {bias, recurrent, obsNorm})` gives the theta layout used by the JS reference (`rlLossAndGrad`, forward `rlPolicyStep`/`rlPolicyMean`, BPTT with leak, checked against finite differences by `rlGradientCheck(seed, features)`) and by the GPU kernels; `rlThetaToGenome`/`rlGenomeToTheta` convert to and from `npc-brain/3`.
Same Backend interface as GpuBackend (create/info/step/readStats/snapshot/exportChampions/importGenomes/checkpoint/restore/setParams/dispose plus `runTests()` and `benchmark()`), selected in the UI by Trainer = PPO. `step()` is one PPO iteration: rollout (`rl_rollout`, one workgroup per world, K ticks, the game chunk unchanged) then `rl_gae`, `rl_advstats`, then epochs x minibatches of `rl_grad` + `rl_reduce_grad` + `rl_adam`, then `rl_rescale` (reward-scale adaptation).
- Policy = the deployed Brain dynamics: hidden h(t) = l (.) h(t-1) + (1-l) (.) softsign(g (W1 x(t) + Wr h(t-1) + b1)), output mu(t) = softsign(g (W2 h(t-1) + b2)), g = 2, outputs have leak 0, no gating, no plasticity; the feed-forward configuration is l = 0, Wr = 0, b = 0. l is one learned leak per hidden unit (geometric time constants 1..leakTauMax, clamped to [0, 0.98]). Fresh characters have h = 0. Training samples a = mu + sigma * eps (learned per-output log-std, clipped to [sigmaMin, sigmaMax]) and the game receives clamp(a, -1, 1); eval and deployment use mu. Value head is linear on the NEW hidden h(t), not deployed. The hidden state is carried across rollouts per learner (double-buffered in the lane buffer), the initial state of every sequence is stored in the rollout buffer, and gradients are truncated at the rollout boundary (BPTT over T = rolloutTicks).
- theta layout (f32): W1 [nIn][H], W2 [nOut][H], logStd [nOut], valueW [H], valueB, then b1 [H], b2 [nOut] (bias), Wr [src][dst] [H*H] and leak [H] (recurrent), then normMean [nIn], normIstd [nIn] (obsNorm; not trained: the running statistics live inside theta so pool snapshots carry them, variance and count sit in the optimizer buffer). Rollout buffers per training learner: T+1 observations (entry 0 is the previous rollout's last observation; with obsNorm they are the NORMALISED inputs the policy saw) plus, for recurrent policies, the H-float initial hidden state, and T records [action(nOut), logp, value, reward/1024, flag (0 alive, 1 dead, 2 truncated at the lifetime cap), truncation value, prevValid, advantage, return]. Lives end at `maxAge` (truncation bootstraps from V of the observation the character would have had, with the recurrent state continued one step) or on `set_dead`; `g_respawn` is called exactly as in evolution and the hidden state resets to 0.
- Eval worlds (last evalFraction, difficulty 100) use mu, respawn every agent fresh at each `maxAge * evalEvery` boundary and report through the same StatsAccumulator/`readStats()` shape (`archive.best` = best eval reward/tick seen, `archive.mean` = mean discounted return of the last rollout in reward units, `archive.count` = iterations, `ppo` = diagnostics).
- Self-play and league: kernel `LEARNERS = game.maxLearners || game.learners`; active slots per world come from the chunk's `g_learner_slots()` (default: all), slots at or above it are scripted bots and are masked everywhere (no records, stats, gradients). Theta buffer = live theta followed by `poolSize` frozen snapshots (slot 0 = latest, others a reservoir of history, one snapshot every `snapshotEvery` iterations). In a `leagueFraction` share of training worlds (re-drawn every `leaguePeriod` iterations) each active slot is driven by that world's snapshot with probability `leagueSlotFraction`: it acts (with noise), dies and respawns like any learner but its samples are masked out of GAE, advantage statistics and gradients. Three fixed eval groups are reported by `readStats()`: `eval` = benchmark worlds (default cfg, 16 learners vs bots, unchanged), `league.headToHead` = worlds where alternating slots run the latest theta and an older snapshot (reference chosen `referenceAge` iterations back, refreshed at eval boundaries; reward/tick of each side and their ratio/diff), `league.selfPlay` = worlds where every slot runs the latest theta (mean life and game stats). Head-to-head and self-play worlds call `g_init(..., randomize = 2u)`, meaning default cfg with all `maxLearners` slots active.
- Export: `exportChampions(n)` -> dense genome, dims {nIn, nOut, nNodes: nIn+nOut+H}, edges input->hidden, hidden->output and (recurrent) hidden->hidden, params gain 2, leak 0 (global; the recurrent export carries a per-node `leak` vector: hidden = learned leak, outputs 0), gateT 0, eta 0, decay 0, pruneT 0, growP 0, inScale 1, wmax = max(weightMax, folded weights). Plain settings export `npc-brain/2` exactly as before; bias, obsNorm or recurrent export `npc-brain/3` (`bias`, `leak`, `inputNorm{folded:true}`; input normalisation is folded into W1 and b1, exact unless an observation exceeds the +-10 normalised clip). `meta` carries logStd and the value head so `importGenomes([genome])` resumes/warm-starts (including unfolding a folded normalisation). `RealtimeNpc` and `Brain` run it unchanged (pass maxEdges >= edge count; `RealtimeNpc` already takes the maximum).
- Options: hidden (<= 256 - nIn - nOut), rolloutTicks, gamma, lambda, clip, lr/lrEnd/lrDecayIterations, entropy, valueCoef, epochs, minibatches, maxGrad, sigmaInit/Min/Max, weightMax, rewardScale (start value, adapted so return std ~ 1 when adaptScale = 1: this is the running return-std reward normalisation), rewardClip (clamp of scaled rewards), valueClip (clamp of value targets), channelCaps (per-tick caps in reward units per channel), advantage normalisation (always on), lifeCapScale, gradGroups, tileEntries, recurrent, bias, obsNorm (obsNormFloor, obsNormCap), recurrentInit, leakInit/leakTauMax/learnLeak, curriculum options, plus worlds, evalFraction, evalEvery, seed, difficultyStart/End/RampTicks.
- Automatic curriculum (`curriculum: 1`, `RlCurriculum` in rl.js, applied at every `readStats()`): difficulty (0..100, starts at curriculumDifficultyStart) rises by curriculumDifficultyStep after curriculumPatience consecutive reports whose smoothed eval (curriculumMetric 0) or train (1) mean life / maxAge is >= curriculumLifeUp and falls when it is <= curriculumLifeDown; with `curriculumSelfPlay: 1` the share of training worlds run as pure 32-learner self-play (no bots, `g_init` randomize = 2u, the others default-cfg 16 learners vs bots) moves from curriculumSelfPlayStart to curriculumSelfPlayEnd as the smoothed eval reward / bot reward ratio goes from curriculumRatioLow to curriculumRatioHigh; worlds whose mode flips are re-initialised by `rl_reinit_world` (header word 2 holds the mode). The state is part of the checkpoint and is returned in `readStats().curriculum` and logged as `CUR[...]` by dev/rllong.html. Evolution already has its own `difficultyAdaptive` controller.

- Population (`policies: K`, default 1 = the single-policy path, bit-identical to the pre-population kernels: checked against a frozen copy over 8 iterations including league snapshots). K <= 8 policies share the architecture and every hyperparameter but each owns: its live theta slice (theta = K live slices then K x `poolSize` snapshot slices, snapshot s of policy p at slice K + p x poolSize + s), its optimiser block (`opt` = K blocks of `optStride` floats: Adam m, v, the CTL block with reward scale / advantage statistics / step counter, running observation variance and count, and `RL_POP_WEIGHT_SLOTS` = 8 reward-channel weights), its observation normalisation, its league pool and reference snapshot, and a reward weight vector over `GameDef.rewardChannels` (per-sample training reward = sum_c w_p[c] x clamp(channel c, channelCaps); `channelCaps` still applies per channel; statistics, the benchmark and `lifeFit` always use the unweighted total so roles stay comparable with each other and with the bots). Every learner lane carries its policy (`LS_POL`) next to its role (live / snapshot) and base slice; `rl_gae` takes each learner's reward scale from its own policy block, every other kernel (`rl_advstats`, `rl_select`, the three gradient kernels, `rl_reduce_grad`, `rl_adam`, `rl_rescale`, `rl_normstats`, `rl_normapply`) is dispatched once per policy through a per-policy bind group whose uniform buffer carries `policy` and masks on `LS_ROLE == live && LS_POL == policy`, so gradients, advantage statistics, normalisation and Adam of one role never see the samples of another. Role assignment per slot (`rl_pop_of`, mirrored by `rlPopPolicyOf` in rl.js): `popMix` 0 balanced (a random rotation per world gives every role its `popFractions` share of the slots), 1 random per slot, 2 archetypes (a `popPure` share of worlds is pure, one random role fills all slots; the rest balanced); `popPeriod` > 0 re-rolls assignments every that many iterations (observation statistics of the last tick belong to the previous policy). League: a snapshot slot is a snapshot of the policy of its role. Benchmark worlds (group A) are split in K + 1 interleaved sets: world i of A is pure role (i mod (K+1)) when that is < K, otherwise the mixed team; head-to-head worlds alternate latest and older snapshots with the same role mix on both sides; self-play worlds are the balanced mix. `readStats().pop` = `{ roles: [{name, weights, fraction, train, evalPure (StatsAccumulator summary of the pure-role benchmark worlds, with game stats), evalMixed (the role's learners inside mixed-team worlds), headToHead, selfPlay, diag, pool}], mixed, evalMean, evalBest, evalBestRole, evalBase, mix }`; `readStats().eval` stays the pooled benchmark. Options: `policies`, `popMix` (0/1/2 or name), `popPure`, `popPeriod`, `popRoles` ('a,b,c'), `popWeights` ('w,w,w,w/w,w,w,w' or arrays), `popFractions` ('a/b/c'); defaults for realm are generalist [1,1,1,1], hunter [0.5,0.5,2,0.5], crafter [0.5,2,0.5,1], forager [2,1,0.3,2]; `configurePopulation(partial)` edits names, weights, shares and mixing live. K > 1 needs at least K + 1 benchmark worlds. Export: `exportChampions` / `exportPopulation(best)` return the bundle, a JSON array of `{format: 'npc-population-member/1', index, role, weights, channels, fraction, genome}` with one normal `npc-brain/2|3` genome per member (`meta.role`, `meta.weights`); `importGenomes` accepts a bundle (matching members by index, restoring roles and weights) or a plain list; the checkpoint carries `pop` (roles, weights, shares, mixing, per-policy pools and references) next to the theta, snapshot and optimiser state of every policy.

## Pruning and distillation (src/prune.js, tools/prune.mjs; CPU, Node worker threads)
Dense PPO genomes (`npc-brain/2|3`, feed-forward or recurrent, any `bias`/`leak`/folded `inputNorm`) become sparse genomes of the same format that `Brain` and `RealtimeNpc` run unchanged: `meta.trainer = 'prune'`, plasticity and structure params zero, `meta.maxEdges` = edge capacity for runtimes that turn plasticity or prune/grow on (the `evalsuite` and `RealtimeNpc` take the maximum of it and the edge count), optional `meta.recommended` from the plasticity sweep. Genomes with an active novelty gate (`params[9]` gateT > 0 and `floor(params[10])` gateMax >= 1) are refused.
- Student = the deployed Brain math on an edge list: inputs current, every other node read from the previous tick, `s(t) = l (.) s(t-1) + (1-l) (.) softsign(gain (sum_e w_e a_src + b))`, per-node `leak`, optional `bias` (added as trainable freedom even when the teacher has none), `inScale`. `ChunkEngine` replays recorded chunks (observations, the teacher's deterministic outputs, its start state) with exact BPTT: feed-forward students use a 1-step burn-in and 24-sample windows, recurrent ones carry the state through 32-step segments (initial state = the teacher's recorded state mapped through `net.orig`). Checked: the dense teacher replays with rmse 1e-7, gradients match finite differences to 1e-7, exported genomes match `RealtimeNpc` exactly and the student math to 1e-6.
- Loss: MSE on all outputs + squared error of the movement differences (game `actionNames` `+x/-x/+y/-y`, weight 2) + a hinge keeping every thresholded output (> 0.5) on the teacher's side; Adam with masked edges, |w| <= wmax, cosine lr.
- Schedule: per target, rounds that keep `ratio` of the edges (default 0.7; saliency `mag` = |w|, `act` = |w| x rms(source activation), `fisher` = mean over 10 minibatches of (w g)^2, `structured` = whole hidden units by rms x norm(outgoing), `hybrid`), `steps` fine-tune steps per round (default 140), `compactNet` after every cut (drops hidden units without an input path or an output path, folds input-independent units into biases, renumbers nodes so `dims.nNodes` shrinks), `finalSteps` (default 420) at the target; `+rewire` = 8 RigL-style rounds (swap 30% decaying to 0: drop the lowest |w| x act, grow the largest |gradient| among the teacher's edges between surviving nodes, new edges start at 0); `+dagger` = the student drives 60% of the slots of fresh worlds while the teacher relabels (aggregated dataset).
- Data: realm bot worlds (16 learners), 32-learner self-play and `randomCfg` worlds, difficulty 100 (some 60/40), 64-tick chunks (192 for recurrent teachers) at life starts and at random times (mean gap 350 ticks) with the teacher shadowing the driver, 1/8 of the chunks held out for validation metrics (RMSE, movement cosine, threshold agreement and recall).

## GPU game contract (WGSL chunk in GameDef.wgsl; documented in GAMES.md)
Kernel (src/shader.js) owns brains, think/learn/structural, graveyard, rebirth, select, reduce. The chunk owns the world simulation over workgroup memory, one workgroup per world, one thread per agent (64 threads). It must define, and the kernel calls uniformly (barriers allowed inside):
`g_load(world,t)`, `g_save(world,t)`, `g_init(world,seed,is_eval,randomize,t)`, `g_step(t,tick)` (reads `action_of(a)` and `out_of(a,k)`, writes `set_reward(a,fx)`, `set_dead(a)`, uses `stat_add(idx,v)`), `g_respawn(t,tick)`, and `g_observe(t,tick)` writing `set_obs(a,i,v)`. Kernel-provided constants: NIN NOUT NODES LEARNERS AGENTS WSTRIDE GAME_OFF, and RNG helpers `pcg mix4 rf`.

## Real-time fidelity (user requirement, non-negotiable)
NPCs must play the real game in real time. Training is the SAME fixed-step simulation run faster, never a simplified proxy:
- A game's Env is the real game logic in fixed timesteps. GameDef has `tickHz` (real-time rate). Live play = the same Env stepped by an accumulator at `tickHz`; training = the same Env stepped as fast as resources allow (K ticks per GPU dispatch is pure acceleration).
- The brain at runtime is byte-for-byte the training brain: same softsign/leaky recurrence, same novelty gate (skipped ticks repeat the last action), same online ABCD Hebbian plasticity and prune/grow every 32 lifetime ticks (plasticity stays ON in deployment). No training-only shortcuts in what an NPC senses, decides or does. Training-only aids (domain randomization, Lamarckian archive, penalty ramp) never change per-tick mechanics.
- Every GPU game port must be a lockstep mirror of its JS Env: GameDef provides `packEnv(env) -> Uint32Array(worldWords)` matching the WGSL `g_save` layout, and GpuBackend.runTests() runs a lockstep parity test (same seed, same scripted action stream, compare packed state words each tick window, plus brain forward/learn/structural parity).
- UI has a Watch mode: run one Env with champion brains at real-time `tickHz` (speed slider 0.25x..max) using the JS Env + Brain, so the user sees exactly what will ship.
- runtime/ must expose a real-time driver: `RealtimeNpc` (per-agent Brain: `decide(inputs, tick)`, `reward(r, tick, died)`, `rebirth()`) and `FixedStepLoop`, the fixed-timestep loop helper used by play.html/server.

## Clarifications (from integration)
- Env.step may read `actions` (argmax with exploration) or `outputs` (raw output activations, -1..1); continuous games read `outputs`. Humans overriding a learner slot must override both.
- `game.render` must be self-contained: the runtime server ships it to browsers via `toString()`.
- `grid` snapshot convention: tile word low 4 bits = type index, bits 4..15 nonzero = on cooldown; games needing exact colours supply `render`.
- Games shipped: `blob` (.io style continuous arena) and `realm` (MMO-style world). See GAMES.md for the authoring guide and the parity checks (GpuBackend.runTests) every GPU port must pass.
- `snapshotFromWords(words, seed)` receives the world seed as second argument.
- Archive fitness decays by ARCHIVE_DECAY_PER_TICK (0.0005) per simulated tick so elites persist for many lifetimes.
